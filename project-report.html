01 / Tóm tắt triển khai

Đã dựng nền tảng ban đầu cho một tool cá nhân chạy trong Claude Code. Hệ thống hiện nhận URL, tạo record cơ bản và xuất workbook Excel có nhiều sheet. Các skill đã được tách riêng để sau này mở rộng discovery, crawl, verify, repair và export.

Trạng thái thực tế

MVP hiện mới là bootstrap và URL-to-Excel smoke path. Chưa phải scraper dữ liệu nhà đất hoàn chỉnh: fetch HTML thật, khám phá API, mapping ngữ nghĩa và verification thực tế là các phase tiếp theo.

02 / Luồng hoạt động mục tiêu

01 · TriggerUser gọi /bat-dau-tim-du-lieu, gửi một hoặc nhiều URL.
02 · Chọn fieldSkill hiển thị field mặc định, hỏi field xuất Excel và xác nhận phạm vi.
03 · RegistryKiểm tra domain, route family và integration artifact đã tồn tại.
04 · DiscoveryWebsite mới được khám phá bằng HTTP/browser; lưu API, feed, schema hoặc fallback script.
05 · ExtractChạy integration active, lấy dữ liệu và giữ URL/evidence nguồn.
06 · VerifySubagent kiểm tra schema, evidence, confidence và cảnh báo.
07 · ExportXuất toàn bộ bản ghi ra Excel; không pre-filter ở MVP.
08 · Human checkUser tự lọc trong Excel hoặc yêu cầu Claude phân tích sau.
09 · RepairParser lỗi tạo candidate version, regression test rồi mới promote.

Quy tắc lọc đã chốt

Không dùng API filter hoặc prompt filter để loại bản ghi trước khi crawl trong MVP. Excel giữ toàn bộ dữ liệu parse được. Khi user hỏi phân tích sau khi có dữ liệu, Claude mới áp dụng điều kiện và giữ nhóm đạtchưa xác địnhkhông đạt riêng.

04 / Playwright MCP

Playwright đã được cài ở hai lớp: Python package để code có thể điều khiển browser và MCP server để Claude Code có thể dùng browser tools khi khám phá website.

Đã cài và kiểm tra

  • playwright 1.65.2 trong virtual environment.
  • Chromium browser đã cài và launch smoke test thành công.
  • @playwright/mcp@0.0.85 đã cài global qua npm.
  • MCP server được đăng ký theo project trong Claude Code.
  • gitnexus ✔ Connected và playwright ✔ Connected khi chạy claude mcp list.
playwright: npx -y @playwright/mcp@0.0.85
  --browser chromium
  --user-data-dir E:/tool-nha-dat/Temp/browser-profile
  ✔ Connected

Cấu hình MCP nằm ở user config của Claude Code, không nằm trong repository. Browser profile nằm trong Temp và đã được loại khỏi Git.

05 / Cài đặt và chạy

Bootstrap một lệnh

.[?25l\setup.ps1

Trên Linux/macOS/Git Bash:

./setup.sh

Script tạo virtual environment, cài dependencies, tải Chromium, đăng ký MCP Playwright nếu có Claude CLI và chạy smoke test.

Chạy thu thập hiện tại

.\.venv\Scripts\python.exe -m src.property_tool.cli --urls-file urls.txt --output research\jobs\property-data.xlsx

Smoke test đã tạo thành công Temp\smoke-test.xlsx và một file kiểm tra trong virtual environment.
